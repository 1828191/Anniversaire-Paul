# Anniversaire Paul

## Mise en ligne
Décompresser le ZIP et remplacer les fichiers à la racine du dépôt GitHub Pages.

Fichiers publiés :
- index.html
- style.css
- supabase.js
- script.js

Le fichier setup.sql ne doit pas être exécuté par le navigateur. Copie son contenu dans Supabase > SQL Editor, puis clique sur Run une seule fois.
